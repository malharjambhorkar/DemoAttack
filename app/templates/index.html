Cybersecurity Mini Project

Phishing Attack Simulation and AI-Based Defense

A presentation-ready Flask demo that shows how deceptive login pages trick users, why MFA matters, and how automated URL screening can help detect suspicious links.

Open Simulation Try Detector

1. Awareness Simulation

A realistic fake login experience for classroom demonstration. The app stores only a redacted preview to keep the demo safe.

2. URL Risk Analysis

The detector uses URL features such as HTTPS usage, digit-heavy domains, suspicious keywords, and unusual structure.

3. Countermeasures

Reinforce best practices: domain verification, avoiding email login links, and using multi-factor authentication.
